This document independently compares the recorded frames 8–15 with fixed-image on-disk x64 instructions; it performs no target operation or replay.

The walk is stronger evidence than the unsynchronized candidate stack scan in `project-activation-stack-21.md`, but it is not a guaranteed globally atomic register/memory snapshot. PSS cloneable shared mappings may be mutable; DbgHelp unwinding and missing/dynamic function tables can introduce errors. The log labels the modules `mapping=image metadata=clone_disk_pe_headers`: matching PE header properties and a local path do not prove all mapped bytes or unwind metadata equal disk, nor identify the runtime targets of indirect calls. Read failure truncates the walk; no complete stack is claimed. The historical private dialog and the prompt-key static consumer are consistent with this partial stack, but this alone does not prove the exact dialog text displayed by a particular UI object, any prompt decision, active project, completed open, or persistence.
