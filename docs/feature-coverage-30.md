# Feature coverage matrix (session 30)

This is the historical session-30 baseline, replacing the older [session-29 matrix](feature-coverage-29.md). Current audio import/export and individual event/note additions are recorded in [session-31 contracts](native-file-services-31.md) and [STATUS](../STATUS.md). "Implemented" and "Verified on the host" below describe session 30, not later coverage. Everything was observed on one machine with one installation and its preferences.

## How the gaps are kept visible

- `cubase://constraints` lists the unsupported areas and the song workflow.
- A command that opened a window during the live probe is not in the allowlist; the test suite keeps those names out.
- `cubase_runtime_windows` and the `windows.unexpected` field of the composite tools report a host window instead of acting on it.
- Receipts say `submitted`; confirmation comes from a separate read (host feedback, channel list, MIDI file, exported file, project file).
