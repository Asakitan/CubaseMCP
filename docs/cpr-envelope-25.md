# CPR envelope inspection 25

`scripts/inspect-cpr-envelope.cjs` is a read-only, bounded inspector for the outer framing observed in local Cubase 16.0.5 fixtures. It expects `RIFF`, a big-endian length equal to file size minus 12, and `NUND`, followed by printable four-byte chunk tags and big-endian chunk lengths. In the inspected fixtures, `ROOT` chunks contain length-prefixed UTF-8 fields and are followed by `ARCH` chunks. The inspector records chunk boundaries and ROOT fields; it does not parse ARCH contents, generate or modify projects, or expose another MCP backend.

Run `node scripts/inspect-cpr-envelope.cjs PATH` with an explicit existing path. It opens a regular file read-only, checks size and chunk bounds, limits chunk count and ROOT descriptor sizes, and compares file identity, size and timestamps before and after using the open handle and current path. An error produces a structured JSON error and a nonzero exit. These sequential metadata checks are not an atomic snapshot, and an unchanged timestamp does not prove unchanged content.

The format description is an observation for the inspected fixtures, not an official format specification or a guarantee across Cubase versions. Passing the envelope check detects neither valid project semantics nor successful save, event content, file durability, or reopen behavior. Persistence verification requires an independently observed host operation, identity/path evidence, and semantic readback or reopening in addition to structural framing.

The fixed test copy `First Empty Probe 24.cpr` produced a 93,085-byte RIFF/NUND envelope with 12 bounded chunks and six ROOT descriptors (`artifacts/ipc/cpr-envelope-25-95a7dc96d45b4ea5856c4b87cad002a6.json`). These include `Arrangement1` / `PArrangement` and `Metadata` / `StMedia::PAttributes`; their presence is a framing observation, not evidence about their contents. A focused synthetic test covers the observed envelope, wrong declared size, an oversized chunk, a malformed ROOT field and a wrong signature.
